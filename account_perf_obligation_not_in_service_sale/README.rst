This module bridges performance obligations marked as *Not in Service*
with sales orders.

Performance obligations created automatically from sale order lines
start as *Not in Service*. Upon confirming a sale order, obligations
whose recognition method starts at order confirmation (*at once*,
*months*, or *days*) are automatically put in service.

.. contents::
   :local:

Usage
=====

1. Configure a product with automatic performance obligation creation
   enabled.
2. Confirm a sale order containing qualifying lines: obligations with a
   recognition method starting on confirmation (*at once*, *months*, or
   *days*) are automatically put in service.
3. Obligations without such a recognition method remain *Not in Service*
   until put in service manually or by another module.
