This module adds milestones to performance obligations using the daily
pro-rata recognition method.

A milestone is a date and a cumulative amount. The obligation is
recognized linearly up to the amount of the first milestone, then
linearly from one milestone to the next, and finally linearly from the
last milestone up to the total amount at the end of the recognition
period.

Usage
=====

1. Create a performance obligation with the *Daily Pro-Rata* recognition
   method and a recognition period.
2. In the *Milestones* tab, add milestones: a date and the cumulative
   amount to be recognized at the end of that date.
3. (Re)generate the schedule entries: one recognition entry is generated
   at each month end and at each milestone date.
